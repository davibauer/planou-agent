# Instruções pessoais do job-scout

Este arquivo é seu (`~/.config/job-scout/config/instructions.md`): o Claude lê antes do primeiro tick e ele **prevalece** sobre o
SKILL.md do plugin onde houver conflito. Atualizar o plugin nunca mexe aqui. Use para regras que só valem para você; critérios
de busca vão no `config.json` (peça ao Claude) e a régua do que faz sentido vai no `profile.md`.

Exemplos (apague e escreva as suas):

- Pacotes de candidatura em `~/candidaturas/` e CVs com o nome `Ana Lima, Resume, AAAA-MM (Empresa)`.
- Nada de travessão no texto que o agent escrever por mim (mensagens, summary do CV, respostas de triagem).
- Nas mensagens de recrutador, responder sempre em inglês, mesmo quando a mensagem vier em português.
- Push no celular só para vaga forte com pagamento em dólar.
