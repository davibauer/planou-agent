# Fixtures do radar técnico

Respostas locais para `radar.py <instância> --dry --fixtures <esta pasta>` e para os testes: cada URL vira um arquivo
`<host>/<caminho>[__<query>]` (`radar.fixture_path`). Dados sintéticos: versões, histórias e repositórios são exemplos,
não notícias reais. Um pacote sem arquivo aqui é tratado como "sem novidade".
