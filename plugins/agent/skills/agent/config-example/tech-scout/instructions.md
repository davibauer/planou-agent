# tech-scout

Radar técnico do time (comportamento tech-radar). Uma vez por semana, as novidades das stacks (versões novas das
dependências dos repositórios do config, blogs oficiais, canais escolhidos, Hacker News e GitHub Trending) viram
sugestões no Backlog do projeto do radar; a tarefa que entra na coluna "Radar técnico" ganha até 3 sugestões na nota e
segue a esteira. Nunca escreve código. Busca externa só com termos genéricos: nada de cliente, caminho ou texto de
tarefa.

Decisões da pessoa (vazias até ela escolher): os repositórios de cliente (`client_repos` da fonte radar_deps), os
canais do YouTube (`youtube` da fonte radar_feeds) e o nome do funcionário no Planou.
